# Изменения

## 0.10.0 - 2026-10-20 (Independent OBS Plugin)

- Плагин выделен в foolka/reward-desk-obs: собственные исходники, C++-панель, модуль обработки, тесты, установщик и GitHub-выпуски v*.
- Продукт фиксирован в исходниках: аргументы запуска и старые маркеры не переключают его на другой профиль. Сборка не требует соседнего проекта.
- Обновления проверяют только свой репозиторий и собственный установщик; добавлены проверки отказа от чужих файлов и старого смешанного канала.
- Профили, базы, медиа, черновики, история, авторизация Twitch, ID установщиков и постоянные ссылки OBS сохранены без миграции и объединения.
- В прежнем GitHub доступен переходный obs-v0.10.0 для старых плагинов. После него обновления OBS идут только из нового репозитория.
- Обновлены инструкции, скриншоты и страницы сайта для двух самостоятельных продуктов.

История ниже описывает совместное происхождение до разделения.

## 0.9.0 - 2026-10-19 (Public App and OBS)

- Первый публичный выпуск Reward Desk и Reward Desk OBS: отдельное приложение Windows или панель OBS с локальным веб-редактором. Профили, вход Twitch и источники независимы.
- Звуковые и видео-награды, рулетки без повторов, веса и громкость отдельных файлов, команды чата, группы и цвета наград.
- Настройка размещения видео, рамки, наклона, индивидуальных подписей и длительности. Постоянная ссылка OBS, очередь и восстановление связи.
- Светлая и тёмная темы, русский, украинский и английский интерфейс. Локальные черновики, история сохранений, резервные копии и защита от случайной подмены профиля.
- Проверка обновлений отдельно выбирает выпуски приложения `v*` и плагина `obs-v*`, независимо от отметки GitHub Latest. Добавлена проверка изоляции каналов обновлений.
- Открыты исходники и история разработки; опубликованы установщики с SHA-256, инструкции и скриншоты. Личные профили и медиа в поставку не входят.

## 0.8.2 - 2026-10-19 (Private App and OBS)

- Перенаправление профиля Windows теперь объясняется спокойным информационным окном вместо системного окна ошибки. Для приложения и OBS-плагина указаны разные шаги обычного запуска.
- Защита данных остаётся включённой: перенаправленная база не открывается, новая пустая база не создаётся. Повреждение базы, ошибки доступа и прочие реальные сбои не маскируются под информационные сообщения.
- Уведомление переведено на русский, украинский и английский; до чтения профиля используется язык системы. Добавлены проверки типа уведомления и остановки запуска до открытия базы.

- Сохраняются награды, медиа, группы, черновики, очередь и прогресс рулеток. Незавершённый показ по-прежнему требует решения без автоматического повтора. Выпуск остаётся приватным.

## 0.6.0 - 2026-10-18

- «Звук» и «Видео» стали вкладками с активным состоянием, фильтрацией списка и сохранением черновиков. Кнопка «Новая награда» создаёт награду выбранного типа.
- Отключённые лимиты и перезарядка показывают 0. В Twitch отправляется выключенный флаг без подставной единицы; включённые ограничения сохраняют свои значения.
- Локальные группы наград: создание, переименование, выбор участников и удаление группы без удаления наград. Можно объединять звуки и видео; во вкладке видна соответствующая часть группы.

- Кнопка «Настроить защиту OBS» находит локальные настройки и подключается без ручного ввода пароля. Если сервер управления выключен, после закрытия OBS подготавливает его автоматически с защищённым паролем и зашифрованной резервной копией прежних настроек. Настройки работающего OBS не перезаписываются.

- Ожидающие награды остаются в очереди. Прерванный показ получает статус «Требует решения» без автоповтора и без автоматического подтверждения покупки.
- Состояние источника всегда видно под вкладками. Дополнительные настройки подключения скрыты; пароль OBS хранится зашифрованным на этом ПК.

## 0.5.4 - 2026-10-17

- Подтверждения остановки и перехода без сохранения заменены окнами внутри приложения: больше нет блокирующего `window.confirm`, после которого на Windows мог теряться клавиатурный фокус полей.
- Прогресс циклической рулетки теперь учитывает начатые показы отдельно от резервов очереди. Отменённые до показа файлы возвращаются в выбор; остановка уже начатого ролика не обнуляет цикл. Работает для звуков, видео, тестов, команд и покупок.
- При отмене ожидающего задания оставшаяся очередь согласуется с циклом без повторов. Тексты и оформление сохраняются из снимка задания, история не удаляется. Прогресс переживает перезапуск.
- Для прежней очереди прогресс восстанавливается по сохранённым началам воспроизведения, без учёта отменённых до старта резервов.
- Источник OBS проверяет версию своих файлов при подключении и перезагружается после будущих обновлений. Уже открытый источник старой версии нужно один раз обновить вручную после установки 0.5.4.
- Добавлены проверки обычного ввода размеров с клавиатуры после подтверждения остановки, быстрых позиций подписи и длительности, обновления источника и длинных очередей через несколько циклов.

## 0.4.0 — 2026-10-17

- Бесплатная активация звуковых и видео-наград командой чата: отдельный переключатель, команда, разрешённые Twitch-ники и общая пауза между запусками. Можно использовать локальную награду без создания покупки в Twitch.
- Только точное сообщение от разрешённого логина в своём канале. Пустой список не открывает доступ всем; команды привязаны к аккаунту и Client ID. Неоднозначные команды блокируются, повторы событий не выбирают новый файл, покупки с сообщением не запускают медиа дважды.
- Команды используют ту же очередь, громкость, оформление и цикл рулетки, что и покупки. В истории видны источник «Чат», команда и зритель; бесплатные запуски не подтверждают покупки и не возвращают баллы.
- Чат подключается через существующий EventSub без отдельного бота. Для него нужен повторный вход с правом `user:read:chat`; старый вход продолжает обслуживать награды за баллы.
- Жирная подпись поверх видео, по умолчанию внизу по центру. Текст, X/Y, размер, цвет и шрифт; пустой текст скрывает подпись. Длинные надписи вписываются в кадр.
- Отдельный переключатель полной длительности текущего ролика в формате `м:сс`, с независимыми X/Y, размером, цветом и шрифтом. По умолчанию располагается над подписью; это не обратный отсчёт.
- Подпись и длительность видны в предпросмотре и OBS, поворачиваются вместе с видео, не добавляют полей к кадру. Для новых опций добавлены подсказки.
- Существующие команды по умолчанию выключены; медиа, история, настройки и постоянная ссылка OBS сохраняются.

## 0.3.0 — 2026-10-17

- Рулетки звука и видео по умолчанию выбирают без повторов, пока не закончатся все файлы с положительным весом. Цикл отдельный для каждой награды, общий для всех зрителей и сохраняется между перезапусками.
- Опция «Полный рандом с повторениями» возвращает прежний независимый взвешенный выбор. В циклическом режиме вес влияет на порядок, а не число показов за цикл.
- На границе циклов исключён немедленный повтор последнего файла, если доступно больше одного. Повтор события Twitch, повтор прерванного задания и тест отдельного файла не расходуют новый выбор; выбор и запись очереди сохраняются атомарно.
- Компактный список медиа: заголовки колонок один раз, громкость и процент в одну строку, уменьшены интервалы и размеры кнопок. Исправлено повторное изменение веса и громкости после сохранения.
- Предпросмотр и OBS используют одну геометрию кадра. Рамка учитывается при вписывании широких, вертикальных и квадратных роликов; добавленных полос нет. Кадр не обрезается и не растягивается.
- Маленькие «?» возле настроек: подсказки при наведении, фокусе с клавиатуры и нажатии. Доступны также для наград только для просмотра; текст не выходит за край окна.
- Сохранены настройки, медиа, очередь, история и ссылка OBS. Уже выбранные файлы в существующих заданиях не заменяются.

## 0.2.0 — 2026-10-17

- Вкладка «Награды канала»: все пользовательские награды Twitch, цвета, цены, статусы, поиск и фильтр по возможности редактирования.
- Редактор доступных через текущий Client ID наград: название, описание, стоимость, цвет, доступность, пауза, сообщение зрителя, лимиты и перезарядка.
- Для наград из других приложений доступен просмотр настроек и переход в панель Twitch. Ограничение на изменение задаётся Twitch API.
- Единая форма настроек для новых медиа-наград и существующих наград канала.
- Проверка изменения аккаунта и устаревших настроек перед сохранением. Обновление списка восстанавливает настройки после потерянного ответа Twitch без повторной отправки.
- Сохраняются медиа, громкости, веса, оформление видео, история и постоянная ссылка OBS.
- Подтверждение ухода из несохранённого редактора; исправлена привязка полей после фонового обновления состояния.
- Новые автоматические проверки и скриншот вкладки.

## 0.1.1 — 2026-10-16

- Исправлено восстановление создания награды через кнопку после потерянного ответа Twitch.
- Индикатор рулетки обновляется сразу при добавлении/удалении файла.
- Пауза перед удалением отражается и в локальных настройках награды.

## 0.1.0 — 2026-10-16

Первый приватный выпуск Reward Desk.

- Отдельная Windows-программа и установщик, собственный профиль и Git.
- Прямой OAuth Device Code Flow и EventSub Twitch, без Streamer.bot.
- Управление наградами канала и доступными настройками Twitch.
- Звуковые и видео-рулетки, веса и громкость каждого файла.
- Визуальное размещение видео, рамка, скругление и случайный наклон.
- Постоянный OBS-источник, очередь, тесты, история, подтверждение и возврат баллов.
- Защита от повторов, восстановление соединения и прерванного проигрывания.
- Скриншоты, инструкции и автоматические проверки.
